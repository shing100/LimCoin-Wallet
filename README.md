# LimCoin Wallet

LimCoin 용 Electron 데스크톱 지갑 (Windows / Linux / macOS).

Electron 메인 프로세스가 LimCoin 노드를 빈 포트에 직접 띄우고,
React 렌더러가 `global.sharedPort` 로 그 포트를 읽어 붙는다.

## 시작하기

```bash
yarn install
cd uidev && yarn install && cd ..

yarn dev          # React 개발서버 + Electron 을 같이 띄운다
```

따로 띄우려면:

```bash
yarn startReact   # http://localhost:3000
yarn start        # ENV=dev 로 Electron 실행
```

배포용 빌드:

```bash
yarn build        # uidev/build 생성
yarn start:prod   # 빌드된 파일을 로드
```

테스트:

```bash
yarn test         # LimCoin 노드의 검증 로직 테스트
```

## 금액 단위

노드와 주고받는 값은 전부 최소 단위(lm) 정수다. **1 LIM = 100,000,000 lm** —
비트코인의 사토시에 해당한다. 화면에서만 LIM 으로 환산하며 부동소수점을
거치지 않는다 (`src/units.js`).

송금할 때 수수료를 지정할 수 있다. 수수료는 별도 출력이 아니라
"입력합 - 출력합" 의 차액이고, 그 트랜잭션을 담은 블록의 채굴자가 가져간다.

**기본값은 노드가 권한 값이다** (`/info` 의 `recommendedFeePerInput`). 노드가
지금 mempool 을 보고 입력 하나당 얼마면 다음 블록에 담기는지 알려 준다.
붐비면 "붐빔" 표시가 붙는다. 예전에는 0.001 LIM 고정이었다 — mempool 이
비어 있으면 그것도 과하고, 붐비면 그걸로는 담기지 않는다. 손으로 고치면
그때부터는 그 값을 쓰고, "권장 … 으로" 를 누르면 되돌아간다.

잔액은 세 가지다.

| | |
|---|---|
| 잔액 | 블록에 담긴 것만 센 확정 잔액 |
| 지금 보낼 수 있는 금액 | 이미 보낸 것과 성숙도까지 뺀 금액 (`spendable`) |
| 묻히는 중 | 아직 못 쓰는 채굴 보상 (`immature`) |

보내고 나면 그 코인은 아직 블록에 없지만 이미 남에게 간 것이다. 확정
잔액만 보여 주면 없는 돈이 있는 것처럼 보인다. 둘이 다를 때만 함께 띄운다.

**채굴 보상은 바로 쓸 수 없다.** 체인이 갈라져 그 블록이 밀려나면
코인베이스는 통째로 사라지므로, 10블록이 쌓일 때까지 기다린다(비트코인은
100블록). 내역에서 "N블록 뒤 사용 가능" 으로 남은 만큼을 보여 준다.

**확인을 기다리지 않고 연달아 보낼 수 있다.** 방금 보내고 남은 거스름돈도
바로 다음 송금의 재료가 된다 — 예전에는 그 거스름돈이 블록에 담길 때까지
묶여서, 잔액이 남아 있는데도 "Not enough funds" 가 났다.

## 노드와의 연결

Electron 메인 프로세스가 노드를 띄우면서 두 가지를 렌더러에 넘긴다.

- `sharedPort` — 노드가 잡은 빈 포트
- `sharedWalletToken` — 지갑 API 토큰

노드의 지갑 엔드포인트(`/me/*`, 송금, 채굴)는 토큰을 요구한다. 이게 없으면
그 포트에 닿는 누구나 코인을 빼갈 수 있다. 토큰은 메인 프로세스 밖으로
나가지 않는다.

체인은 `app.getPath("userData")/chain` 에 저장된다. 포트는 뜰 때마다
달라지므로 포트별 기본 경로를 쓰면 재시작할 때마다 새 체인이 된다.

브라우저로만 띄워 시험할 때는 노드를 `LIMCOIN_WALLET_TOKEN=none` 으로
띄우거나, 콘솔에서 `window.LIMCOIN_WALLET_TOKEN` 에 토큰을 넣으면 된다.

## 백업

지갑 화면의 **백업** 카드에서 니모닉 24단어를 볼 수 있다. 이 단어들만
있으면 지갑을 통째로 되살릴 수 있으므로, 기본은 가려 두고 눌러야 보인다.

씨앗을 16진수로 두면 사람이 옮겨 적기 어렵고 한 글자만 틀려도 지갑을
잃는다. 니모닉에는 체크섬이 있어 잘못 적으면 대개 걸린다.

## 주소와 내역

거스름돈을 새 주소로 받으므로(백서 10장) 지갑은 주소를 여럿 갖는다.
잔액 카드에서 주소 목록을 펴 볼 수 있고, "새 주소" 로 받는 주소를 더
만들 수 있다.

내역은 노드의 주소별 색인에서 받는다. 주소마다 받아서 txId 로 합친다 —
한 트랜잭션이 보낸 주소와 거스름돈 주소를 함께 건드릴 수 있기 때문이다.

> 예전에는 블록을 500개씩 받아다 여기서 훑어 만들었다. 그래서 내역이
> "최근 500블록"으로 잘렸고, 노드가 이미 아는 것을 다시 계산했다.

**아직 블록에 담기지 않은 것도 내역 맨 위에 뜬다** (`GET /me/pending`).
보내고 나면 블록이 나올 때까지 아무 흔적도 없어서, 보내진 건지 알 수
없었다. 담긴 뒤에는 그 위로 블록이 몇 개 쌓였는지(확인 횟수)를 보여 준다.

"얼마를 썼는가"는 입력이 가리키는 이전 출력을 되짚어야 알 수 있고 그건
UTxOut 집합을 가진 노드만 할 수 있다. 그래서 노드가 계산해 준다.

## 받을 주소 QR

잔액 카드에 받을 주소의 QR 이 함께 뜬다. 받을 주소를 남에게 알려 주는 일은
지갑에서 가장 자주 하는 일인데, 지금까지는 34자를 복사해 메신저로 보내는
길밖에 없었다 — 상대가 휴대폰 지갑을 쓰면 그걸 다시 손으로 옮겨 적어야
했고, 한 글자만 틀리면 돈이 사라진다.

QR 은 `uidev/src/qr.js` 에서 직접 만든다(byte 모드, 오류정정 M, 버전 6까지).
QR 을 만들어 주는 웹 서비스에 넘기지 않는 이유는 두 가지다 — 받을 주소를
바깥에 알릴 이유가 없고, 지갑은 아예 오프라인에서도 떠야 한다.

다크 화면에서도 **검정/흰색 그대로** 그린다. 반전시키면 보기에는 어울리지만
반전된 QR 을 못 읽는 스캐너가 아직 많다. "예쁘게"보다 "반드시 읽힌다"가
먼저인 자리다.

"주소 복사" 는 `navigator.clipboard` 가 없는 환경(보안 컨텍스트가 아닌 곳)
에서도 동작한다. 예전에는 그런 곳에서 눌러도 **아무 일도 일어나지 않았다** —
사람은 자기가 잘못 눌렀다고 생각한다.

## 화면 밝기

자동(OS 를 따름) · 라이트 · 다크. 헤더 오른쪽 단추로 돌려 가며 고르고,
고른 값은 `localStorage` 에 남는다. 지갑은 종일 띄워 두는 창이라 OS 는
다크로 두고 이 창만 밝게(또는 그 반대로) 쓰고 싶은 경우가 실제로 있다.

바탕값은 **다크**다(익스플로러는 라이트). 그래서 CSS 규칙의 모양도 뒤집혀
있다 — `uidev/src/ui.js` 의 `baseStyles` 주석 참고.

## 개인키

노드 지갑의 개인키는 `LimCoin/src/privateKey` 에 저장되며 첫 실행 시 자동 생성된다.
**`.gitignore` 대상이고 절대 커밋하면 안 된다.**

> 과거 버전은 제네시스 주소의 개인키를 저장소에 함께 커밋했다.
> 그 주소는 폐기되었고 해당 키는 더 이상 사용해서는 안 된다.

들어 있었다. 원본이 바뀌면 `LimCoin/src`, `LimCoin/scripts`,
`LimCoin/test`, `LimCoin/package.json` 을 직접 맞춰 줘야 한다.

같은 체인에 붙으려면 **`LimCoin/src/genesis.json` 이 접속하려는 노드와
동일해야 한다.**

## 로고

브랜드 마크는 **금화 안에 블록 네 개로 쌓은 L** 이다 — 익스플로러와 같은
마크를 쓴다. 라이트/다크 어느 쪽에서도 색이 같다: 상표는 배경이 바뀐다고
색이 바뀌는 것이 아니고, 그래야 창 아이콘·파비콘과 화면 속 로고가 같은
물건으로 보인다.

모양의 원본은 `uidev/src/logo.json` **하나뿐**이다. 헤더의 로고
(`uidev/src/components/Logo.js`)와 파비콘·창 아이콘이 같은 좌표를 읽는다.

```bash
cd uidev
node scripts/icons.js         # SVG 만 (의존성 없음)
node scripts/icons.js --png   # PNG·ICO 까지 (headless Chromium 필요)
```

일렉트론 창 아이콘도 여기서 나온 `icon-512.png` 를 쓴다(`main.js`). 예전에는
지정하지 않아 **기본 일렉트론 아이콘**이 작업표시줄에 떴고, 파비콘은
create-react-app 이 넣어 준 **리액트 로고**가 그대로 남아 있었다.

## 글꼴

본문은 [Pretendard](https://github.com/orioncactus/pretendard)(SIL OFL 1.1)를 쓴다.
`uidev/public/fonts/pretendard/` 에 함께 두었다 — 데스크톱 지갑은 오프라인에서도
떠야 하므로 CDN 을 쓰지 않는다.

동적 서브셋판이라 파일이 92개지만 화면에 실제로 쓰인 글자가 든 조각만 읽힌다.
익스플로러와 같은 글꼴·같은 디자인 토큰을 쓴다(`uidev/src/theme.js` 와
`LimCoin-Explorer/src/theme.js` 는 같은 값이어야 한다).
